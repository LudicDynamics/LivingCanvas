あなたは小屋の木のテーブルで目を覚まします。屋根に雨音が響いています。ここにどうやって来たのか覚えていません。

封がされた手紙、暗い画面の電話、そして開いた扉があります。扉が細く開いているのは、たった今、誰かがそこを通ってきたから。アイリスと名乗る女性で、見えるかぎりもう一つしかない扉の向こうに住んでいて、あなたのランプが点いたので渡ってきたのだと言います。

手紙を読むか、電話を試すか、彼女に知っていることを尋ねるか、外へ出るか。あなたの選択が次に見つけるものを形作ります。
