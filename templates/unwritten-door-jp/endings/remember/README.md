手紙と電話、そして扉の外の場所が実際に見せてくれたものから、あなたは声に出して組み立てる。自分が誰なのか。なぜこんな扉が自分のために開いたのか。アイリスは口を挟まない。ようやく答えの見つかった一文を聞いた人のように、一度だけうなずく。

雨はやんでいる。もう一度扉を見ると、その向こうはただの朝だった。開ける前から、そこにあった場所。

アイリスは敷居まで見送り、そこから先へは来ない。振り返ると、彼女は封をしたままの自分の封筒を両手で裏返していて、初めて、その封の下に爪を差し入れた。

あなたは自分の名前を持って外へ出る。あの部屋のことは、忘れない。
