あなたははっきり言う。ここを出る、ひとりでは行きたくない、と。アイリスは長いあいだ扉を見つめ、それからあなたを見て、掛け釘から上着を取った。誰かにそう言われるのを、ずっと待っていたみたいに。

外にあるのは、扉があなたのために書いた場所——一度もう歩いた場所だ。今度はふたりとも小屋を振り返らない。背後でランプがひとりでに消え、曲がり角に着く前に雨がやむ。

道の途中で、彼女はポケットから自分の封筒を出し、一度だけ裏返して、封を切らずに戻した。「あとで」と彼女は言う。「扉を開ける前から、そこにあった場所に着いたら」

どうやってここに来たのか、あなたはまだ知らない。でも今度は、あの部屋を覚えている人がもうひとりいる。そしてあなたも、彼女を覚えている。
