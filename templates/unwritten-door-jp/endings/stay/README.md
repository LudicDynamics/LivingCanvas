あなたは扉を閉め、掛け金を下ろす。外にあるものは、書かれないままでいい。アイリスは長いことあなたを見ていたが、やがてもう一脚の椅子を引き、欠けたマグふたつにお茶を淹れた。何がどこにあるか、全部知っているみたいに。

雨はやまない。ひどくもならない。ランプが細くなるまで話して、細くなるたびに、誰かがもう芯を切りそろえている。

夜がいくつも過ぎる。あるいは、ひとつの夜が過ぎ続ける。手紙はあなたが置いた場所にある。彼女の封筒も、封をしたままだ。

ある晩、向かいの、一度も開くのを見たことのない扉の奥にランプが灯る。アイリスが立ち上がる。「行ってくる。誰かが目を覚ましたから」あなたは気づく。あの一文に慣れた側になるくらい、自分はもう長くここにいるのだと。
