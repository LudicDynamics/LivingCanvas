你把材料放回原处：还温着的星星碎片，只映着烛光的手镜，两个始终没有念出口的词。

塞拉菲娜没有拦你。她把你的草稿对折一次，夹进笔记本的最后一页。「没念出来的咒语，还没让你付出任何东西。」她说，「它只是还没发生。」

今晚，图书管理员什么也没有登记借出。出门时你低头看了看名牌，名字那一栏依然空白。

明天晚上，图书馆还会在同一个时刻开门。材料会在你放下的地方等着。
