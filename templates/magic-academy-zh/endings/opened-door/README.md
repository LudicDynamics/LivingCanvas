你回到夜晚的图书馆，刚起好的咒语名字还温在舌尖。身后的储藏室里，咒语打开的那片空间还在——你移开视线，它也没有合上。

塞拉菲娜替你留着阅览桌旁的座位。她请你把那个名字再说一遍，然后写在自己笔记本的页边，就写在你答应付出的代价旁边。

「第一个咒语，大多只是打开一个抽屉。」她说，「你的打开了一个能走进去的地方。记住你付了什么，下一个咒语也会是你自己的。」

图书管理员像登记一本书那样，把它记进借阅簿：今晚借出，什么时候准备好了，什么时候归还。
