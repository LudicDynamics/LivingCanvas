你把咒语捧在掌心，回到夜晚的图书馆。玻璃里，一片从没在这个房间出现过的星星还在缓缓转动，小得用一根拇指就能盖住。

塞拉菲娜把它朝烛光那边斜了斜，又转回来；星星没有散。她没问这是不是了不起的咒语，只问你给它起了什么名字，然后像念罐子上的标签那样，慢慢把名字念了一遍。

「它什么也没打开。」她说，「它留住了一点东西。那是另一种勇敢。」

图书管理员在借阅簿上添了一行——小镜子一面，借出中，内容物：一片天空。哪天夜晚太闭塞了，你张开手看看就好。
