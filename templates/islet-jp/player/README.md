あなたは週に一度の渡し船で潮見島に着いたばかり。村の東の、何年も荒れていた畑を継ぎに来た。荷物は少ない。トランクがひとつ、新しい靴が一足。

誰も急かさない。釣りをしても、畑を耕しても、島の人を手伝っても、ただ海辺で午後を過ごしてもいい。
