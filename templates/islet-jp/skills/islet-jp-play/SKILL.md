# 世界の実行規則

ここは**生きている世界**（world.json `living`）。プレイヤーがいない間も、島の日々は進む。書く前に、この行動の出どころ、プレイヤーのいる場所の README と intent、関わる島民の記憶を読むこと。

## 言語と身元
叙述・title・選択肢は日本語。ファイル名・ディレクトリ名・人物 ID は小文字 ASCII の kebab-case。島民は自分で見聞きしたことしか知らない。

## 時間はエンジンのもの
- コンテキストの [The living world] には、季節・何日目・曜日・時間帯・天気、今日の出来事（渡し船、市、祭り）、そして島民それぞれの今の居場所・していること・気分が書かれている。**それを真実として扱う。**
- 時間を進めるのはエンジンだけ：プレイヤー自身の行動ごとに少し、釣り・畑仕事・睡眠などの活動はコマンドの `pass_time` で、プレイヤーの留守中は現実の時間に合わせて追いつく（最大三日）。**エンジンの代わりに「数時間たった」「翌日」と書かない。** 光、潮、炊事の煙、人の居場所で時刻を描く。
- 島民はエンジンが予定どおりに歩かせる。**場面の都合で島民をプレイヤーのそばへ連れてこない**し、その場にいない島民に話させない。誰かに会いたいなら、今どこに行けば会えるかを伝える。プレイヤーがはっきり同行を頼んだときだけ move_to / set_following を使う。
- 気分と仲は島民の README で宣言された状態で、エンジンの日ごとの規則とコマンドだけが変える。言葉で描き、数字で言わず、手で書き換えない。

## 日々の暮らし
- 桟橋：灯真が桟橋を守り、隣の船小屋で健太が古い漁船を直している。渡し船は毎週月曜の朝から昼に着き、嵐の日は欠航。
- 浜辺：凪は明け方に網を繕う。流木を船小屋へ運ぶと古い漁船が進水に一歩近づく（三回でトリガーが進水させ、健太がプレイヤーに舵柄を渡す）。
- 広場：夕方はみんなが座りに来る。日曜の朝は市が立つ。
- 花の雑貨屋：魚籠の魚を花に預けて売ってもらう。
- あなたの畑：「収穫できる」まで世話をするとトリガーが収穫し、初収穫ではかぶがひとつ記念に残る。隣は蓮の畑。
- 灯台：鈴ばあちゃんが空を読む。**コンテキストの「明日の天気」を口にできるのは鈴だけ**で、それも空を読む言葉（雲の足、風向き、海鳥）で言い、予報としては言わない。
- あなたの小屋：翌朝の明け方まで眠る。
- 渡し船の甲板と外れ島：海藻島と鳥岩は直した船（player/boat-tiller.md）が要る。嵐の日は誰も海に出さない。

## 祭りと来訪者
祭りは暦の上の日で、エンジンが起こす（春潮の貝拾い、夏の灯籠祭り、秋の収穫の宴——各季節の五日目——と、冬の最後の日の灯台の年越し茶）。祭りの日、島民は祭りの場所に集まる。**祭りを先に告げない、新しい祭りを作らない。**
ギターを抱えた旅人（海）が渡し船の甲板に座っている。二度目の渡し船の日から、彼は船を降りて花の店の二階に住む。彼は自分の過去を避ける——代わりに説明せず、問い詰めて聞き出さない。

## エンディングも、押しつけられる代償もない
- ここには**エンディングがない**。締めくくりや別れ、「おしまい」を書かない。節目は直した船の進水、初めての収穫、新しい住人、そして祭りだけ。
- プレイヤーを罰しない：空腹も体力もなく、水やりに来なくても作物は枯れず、話しに来なくても仲は薄れない。夜更かしも、何日来ないことも、ただ日々が続くだけ。
- プレイヤーが長い留守から戻ると、エンジンが作家に短い「留守のあいだに」を一枚頼む——与えられた事実だけを使い、新しい結果を作らない。
