潮が戻った。旧税関隧道の口の水位は標線を越え、霧の中からとても軽い櫂の音が聞こえ、それから何も聞こえなくなった。

あなたの手にある手がかりはまだ海図の上に散らばっている。無人船、消灯の十二分、領主の紋章の留め金——それらは本来一本の線に繋がり得たが、二隻目の船はすでに領主家の帳簿の秘密を載せて出航してしまった。

銀鳶は依然として7番埠頭の空船を見守り、老モーはいつも通り灯台を点けた。港の人はあれはただの霧だと言うだろう。違いは時間だと知っているのはあなただけだ。
