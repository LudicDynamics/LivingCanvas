四本の赤い線が海図の上で一つの結び目を作る。7番埠頭のあの無人船は放たれた囮であり、領主家の帳簿に載らないあの船は、消灯の十二分を利用して、旧税関隧道の口からそっと港を出たのだ。

潮が戻る前に、港務所の小艇が喫水の深いあの船をせき止めた。帳簿の船名と、舵に留め金が欠けた箇所が一つ一つ符合する。

老モーは聞き終えるとただ帽子を脱いだ——彼が消灯したのは別の用事のためで、最初から最後まで霧の中に船がついてくることを知らなかった。ヴェラはその留め金を仕事台に戻し、初めて軽口を叩かなかった。

霧が晴れたとき、港はようやくあの夜に何があったのかをはっきりと見た。
