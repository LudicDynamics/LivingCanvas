地上的光环一道一道暗下去，像有人在用手指抹掉粉笔线。

莉拉没有争辩。她朝你低头行了一礼，像骑士向再也不会相见的人告别那样，从断拱外涌进来的海雾先带走了她的铠甲。

到了早上，天文台不过是悬崖上的一片废墟。湿漉漉的石头上躺着一条蓝丝带。不管那扇门外会来什么，你都要独自去面对了。
