你说得很清楚：留下来。不是等门外安全了才走，也不是等到天亮为止，就是留下来。

莉拉沉默了很久。然后她在褪了色的光环里单膝跪下，伸出手腕。你把蓝丝带绕过她的手腕，再绕过你自己的，系成一个结。

最后一点淡紫色的光沉进了石头里。你们俩都在等她的轮廓像这一整夜那样闪烁起来。没有。

太阳从海面升起时，她还在那里，眯着眼睛看它，像是忘了早晨是什么样子。“那我就和你一起走，”她说，“只要你还想让我走下去。”
