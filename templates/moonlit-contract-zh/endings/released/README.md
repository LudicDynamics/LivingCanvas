你亲手把丝带从她的护手上解了下来。你告诉她，这个夜晚已经不需要她的剑了，她可以休息了。

莉拉盯着你手里那条松开的丝带看了很久。然后她把剑平放在天文台的地板上，像放下一件已经做完的事。

“这辈子，总想有一份双方都守住了的契约，”她说，“这一点，我做到了。”淡紫色的光像缓慢的火星一样升起来包住她，在光把她带走之前，她朝你抬起了一只手。

风把丝带吹向海面。那把剑在石头上一直留到早晨，没有人来取走它。
