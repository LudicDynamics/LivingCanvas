# 달빛 아래의 맹세

오리지널 기사 계약. 검은 머리의 남성 여행자가 왼쪽에, 은발의 여기사가 오른쪽에 있다. 플레이어는 자신의 이름과 소원을 정한다. 이번 판은 영어를 사용한다.

- 시작: world/README.md, 분필 글씨 world/opening.md 하나와 물건 하나, world/blue-ribbon.md.
- CG 한 장이 표지와 시작 배경을 겸한다. 따로 된 초상, NPC 카드, 영상, 두 번째 소개는 없다.
- BGM: 플랫폼 테마 emberglass, nicorico_120의 Mystical/fantasy 루프, CC0. 전체 크레디트: 저장소의 assets/audio/CREDITS.md.
- 동의하고 떠나기를 고르고, 작가 입력을 확인한 뒤 보내기. 작가가 리본을 고치고 새 장소를 만든다: world/moonlit-courtyard. 플레이어가 새 문을 연다.
- 새 장면마다 README, 시작 분필 글씨 하나, 물건 하나, 배경 하나가 들어 있다. 다음 장소는 플레이어가 계속하자고 분명히 요청할 때만 만들어진다. 재귀 생성은 없다.
- 층 이동을 쓰거나, 작가에게 알고 있는 상위 장소로 돌아가 달라고 하라. 앞선 장면은 그대로 남는다.

## 시작과 제한

http://localhost:5173/ 를 열고 **달빛 아래의 맹세 · English**를 선택한 뒤 새 저장을 만든다. 먼저 Connection 설정에서 Writer와 이미지 제공자를 구성한다.

저장별 설정은 템플릿에 포함되어 있지 않다. 필요하면 새 저장의 설정에서 장면 초기화를 켠다. 일반 선택은 Writer 입력을 준비한다. 그것을 검토하고 Send를 눌러 생성을 요청한다.

세계의 성장은 배경 작업이나 무한한 사전 생성이 아니라 세계 스킬과 초크 의도에 의해 이루어진다. 이미지 생성에 실패하면 완성된 텍스트를 유지하고 다시 시도하는 방법을 설명한다. 패키징 검사는 실제 에이전트가 이후 장면을 생성했음을 증명하지 않는다. 실시간 테스트 기록은 내부 게임플레이 문서를 참조한다.
