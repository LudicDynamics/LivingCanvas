あなたは自分の手で、籠手からリボンをほどく。この夜にもう君の剣は要らない、休んでいい、と告げる。

ライラはあなたの手の中のほどけたリボンを長いこと見つめていた。それから剣を天文台の床に横たえる。終わったものをそっと置くように。

「生涯に一度でいい、双方が守った契約を持ちたかった」と彼女は言う。「それが叶いました」淡紫の光がゆっくりとした火の粉のように彼女を包み、消えていく間際、彼女はあなたに片手を上げた。

風がリボンを海の上へ運んでいく。剣は朝まで石の上に残り、誰も取りには来なかった。
