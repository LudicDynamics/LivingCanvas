床の円が、チョークを指でこすり消すように、一本ずつ暗くなっていく。

ライラは言い返さない。もう会うことのない相手に騎士がするように一度だけ頭を下げ、崩れたアーチから入り込んだ海霧が、まず彼女の鎧をさらっていった。

朝になれば、天文台は崖の上の廃墟にすぎない。濡れた石の上に青いリボンが一本落ちている。あの扉から何が来るにせよ、あなたは一人でそれに向き合う。
