あなたははっきりと言う。ここにいてほしい。扉の外が安全になるまでではなく、夜が明けるまででもなく、ここに。

ライラは長いあいだ黙っていた。それから色の薄れた円の中に膝をつき、手首を差し出す。あなたは青いリボンを彼女の手首と自分の手首に回し、一つの結び目で結ぶ。

最後の淡紫の光が石に沈んでいく。一晩じゅうそうだったように、彼女の輪郭が揺らぐのを二人で待つ。揺らがない。

海の向こうから日が昇っても、彼女はまだそこにいて、朝の光を忘れていた人のように目を細めている。「では、あなたと歩きます」と彼女は言う。「あなたが望み続けるかぎり」
