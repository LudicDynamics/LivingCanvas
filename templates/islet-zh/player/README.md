你刚坐每周一班的渡轮来到潮见岛，接手村子东边那块荒了几年的田。行李不多：一只箱子，一双新鞋。

没人催你做什么。你可以钓鱼、种地、帮岛民的忙，也可以只是在海边坐一下午。
