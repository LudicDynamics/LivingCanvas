你在小屋里的一张木桌前醒来。雨点轻敲着屋顶。你不记得自己是怎么来到这里的。

桌上有一封封好的信、一部黑着屏的手机，还有一扇没上锁的门。门半开着，因为刚刚有人从那儿进来：一个自称艾莉丝的女人，住在你能看见的、仅有的另一扇门背后，她说她是看见你这边灯亮了才过来的。

读信、试试手机、问问她知道些什么，或者走出门去。你的选择将决定你接下来会发现什么。
