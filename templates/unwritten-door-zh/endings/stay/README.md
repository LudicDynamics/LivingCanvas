你关上门，插好门闩。外面是什么，就让它一直不写出来吧。艾莉丝看了你很久，然后拉开另一把椅子，用两只缺了口的杯子泡了茶，好像她知道每样东西都放在哪儿。

雨没有停，也没有变大。你们一直聊到灯芯变短，而每次变短，总有人已经把灯芯剪好了。

一夜一夜过去，又或者，同一个夜晚一直在过去。信还放在你放下的地方。她那封也一直没拆。

某天晚上，对面那扇你从没见它打开过的门后，亮起了一盏灯。艾莉丝站起来：“我去吧，有人刚醒。”你这才发觉，你在这儿待得够久了，久到成了习惯那句话的那一个。
