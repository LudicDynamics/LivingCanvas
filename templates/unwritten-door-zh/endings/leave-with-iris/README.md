你说得很清楚：你要走，而且不想一个人走。艾莉丝盯着那扇门看了很久，又看看你，从挂钩上取下外套，像是等这句话等了很久。

门外是那扇门为你写出来的地方，你已经走过一次。这一回，你们谁都没有回头看木屋。身后的灯自己灭了，还没走到拐弯处，雨就停了。

走到半路，她从口袋里掏出自己那封信，翻过来看了一眼，又原封不动地放了回去。“以后再说，”她说，“等我们走到一个开门之前就已经在那儿的地方。”

你还是不知道自己是怎么来的。可这一次，记得那个房间的人不止你一个，而你也会记得她。
