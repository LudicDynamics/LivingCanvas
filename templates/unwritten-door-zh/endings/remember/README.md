你把信、电话，还有门外那个地方真正告诉你的东西，一样一样说出来，拼到一起：你是谁，为什么会有这样一扇门为你打开。艾莉丝没有插话。她只点了一下头，像一个人终于听见某句话有了答案。

雨停了。你再看那扇门，门外只是早晨，一个在你开门之前就已经在那儿的地方。

艾莉丝送你到门槛，就不再往前。你回头时，她正用两只手翻着自己那封还没拆的信，第一次，把指甲探进了封口底下。

你带着自己的名字走出去。那个房间，你不会忘。
