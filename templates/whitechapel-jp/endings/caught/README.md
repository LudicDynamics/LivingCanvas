あなたは証拠をひとつずつウェインの前に並べた。事件より先に届いた挿絵、現場の手すりの群青、手首の新しい傷、そして8時15分に彼が受け取った訂正稿。

ウェインは長いあいだそれを見つめ、やがて赤い封筒から手を離した。中身は第四の絵の校正刷り――封筒を受け取る人物は、イーディスの顔をしていた。

レストレードの部下が彼を連れていくとき、ちょうど正午の鐘が鳴った。何も起こらなかった。

イーディスは221Bの客間で第四章を書き上げた。今度は、誰にも先に読ませなかった。
