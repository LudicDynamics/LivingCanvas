# 소재 목록

승인된 원본 파일은 Canvas 빌드 캐시가 아니라 worldlines-assets/worlds/wuwu-demo에서 가져온다. 원본 파일과 출력의 체크섬은 source-manifest.json에 있다. 이미지는 /api/asset을 통해 제공된다. 기존 내러티브 파일과 목록에 없는 옛 소재는 모두 유지한다.
