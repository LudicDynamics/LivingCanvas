# 世界実行規則

これは本当にファイルを更新するゲームであり、しかも一局が**終わる**ゲームである（world.json `mode: closed`）。まず今回の行動の出所、現在いる車両とそのREADME、intent、関連する実物、人物の記憶を読むこと。READMEは場所と出口を記し、Chalkは現在の選択を記し、本skillは世界の不変条件を記す。intentは作家への指示であり、エンジンの命令ではない。

## 言語と知識
叙述、title、選択肢は日本語で書く。ファイル名、ディレクトリ名、人物IDは小文字ASCIIのkebab-caseを使う。人物は自分が目撃したか聞いた事実しか知らない。蘇禾、周子航、運転士の秦じい、料理人の賀じいは登録キャラクターではなく、NPCカード（`type: npc`：world/freight-car/su-he.md、world/seated-car/zhou-zihang.md、world/cab/lao-qin.md、world/dining-car/lao-he.md）であり、プレイヤーはカードの「会話」をクリックして彼らと話す。彼らのためにキャラクターや別の会話ボタンを新たに作らないこと。

## 流れ（三幕）
この一局は三幕構成。流れは骨組みであってレールではない：プレイヤーはいつでも自由に行動でき、作家はルールに従って応える。
- **第一幕・2号車 硬座（開始地点、キャンバス）**：夏澄が先に話しかける → プレイヤーが17番の座席のノートを手に取る → ダイスで20番の学生に尋ねる（または周子航の「話す」）→ 証言を得る → 3号車へ、または列車の地図へ戻る。序章から来たプレイヤーは早送りできる（01-opening.md の `skip-act-one`、エンジンが `command/prologue-carry.yaml` を実行：ノートと証言が鞄に入り、時計が一歩進み、総覧へ直行）。
- **第二幕・車両のあいだ（総覧は地図、各車両はキャンバス）**：三つの筋は順不同、それぞれに謎が一つ——**寝台車**（扉口のグレーのウールコートは誰のもの？彼は本当に十一時半に寝たのか？個室を捜索すると薬のシート）、**食堂車**（4号卓の二杯のお茶は誰のつけ？捜索すると石炭入れから5号車の鍵）、**運転室**（復旧通知：0時42分から1時5分まで運転室は無人、鍵のフックは空；無線）。
- **第三幕・5号車 荷物車（キャンバス）**：鍵で扉を開ける → 蘇禾を起こす → 鐘懐礼が扉口を塞ぐ（決定的判定）→ 報告：夏澄に運転室から無線を打ってもらう（06-radio-relay.md）か、自分で運転室の無線へ戻る（02-radio-report.md）。どちらも同じ `command/report-truth.yaml` を実行する。

## 選択肢は誰のものか（作家の／キャラクターの）
- カードの選択肢は二種類：**作家の**（世界が変わる行動：入る、取る、読む、捜索、ダイス）はプレイヤーの作家トレイに出る；**キャラクターの**（`to: xia-cheng` / `to: zhong-huaili` / `to: companion`、`say` 付き）はプレイヤーがその人に**言う言葉**で、その人の吹き出しに出て、作家を通さず直接キャラクターに送られる。作家はキャラクターの選択肢を扱わない。
- 夏澄のヒントはあらかじめ書かれている（世界ルートの `hints.json`、エンジンが一拍ごとに一つ選び、「夏澄がプレイヤーに言った……」という出来事として彼女の記憶に入る）。作家はその表の言葉を繰り返したり、書き換えたり、先回りして言ったりせず、ネタばらしのためにファイルを読まないこと。

## 固定真相（作家だけが見るもので、先に口に出してはいけない）
- 十二年前の十一月七日、断雲トンネルで二両の列車が衝突し、三人が亡くなった。信号係の蘇長庚が職務怠慢とされた。真相はこうだ：01:12 指令の鐘懐礼が「赤信号で進め」と口令を出し、蘇長庚は異議を唱えた後にそれに従い、運転日誌に記した。事故後、そのページは記録から消え、ずっと蘇長庚の手元にあった。
- 今晩、蘇長庚の娘・蘇禾（2号車17番）がその日誌のページを持ってK7列車の終電に乗り込んだ。鐘懐礼（3号車3番下段、現分局副局長）は嶺口へ事故十二周年の追悼式に出席し、挨拶をする。
- 23:20 食堂車4号卓で、蘇禾は鐘懐礼に日誌のページを見せ、追悼式で認めるよう求めた。鐘懐礼は彼女にお茶を勧め（彼の勘定で）、彼女の茶碗に自分の睡眠薬を二粒入れた。
- 00:40 前方で土砂崩れがあり、列車は断雲トンネルの真ん中で止まった。00:42 運転士の秦じいが提灯を持って下車して確認し、01:05 戻った。この間、運転室は無人だった。
- 約00:44 鐘懐礼は運転室の鍵板から「5号車 荷物車」の鍵を外して持ち去った（彼は鉄道に詳しく、鍵がどこに掛かっているか知っている）。約00:50 彼は2号車で朦朧とする蘇禾を抱え起こし、「彼女は車酔いだ、後ろで風に当たらせてくる」と言い、それを学生の周子航が目撃した。彼は蘇禾を暖房のない荷物車に閉じ込め、彼女のコートの内ポケットから日誌のページを奪った。帰りに食堂車を通る時、彼は運転室に鍵を掛けに戻る勇気がなく、鍵を湯沸かし器のそばの石炭入れに投げ込んだ。コートの裾に郵袋のジュート繊維が付いた。
- 01:10 夏澄が人数を数え、17番の席が空いていることに気づき、隣の18番に座っていたプレイヤーを起こした。
- 日誌のページは鐘懐礼のコートの内ポケットにあり、プレイヤーが荷物車で彼を止めるまで（決定的判定）そこにある。彼は人を殺したいわけではなく、あの紙を消したいだけだ；しかし荷物車はひどく寒く、蘇禾は夜明けまで持たない危険がある。
- 答えはこれ一つだけ。犯人、動機、時間線、物の位置を書き換えてはいけない；第二の犯人や共犯を出してはいけない。秦じい、賀じい、周子航は皆無実だ。

## 手がかりの配置（公正な手がかり）
| 車両 | 無料で読める／取れる | 捜索報酬（13–60 か 1–12 で手に入る。61–100 は半分の手掛かりだけ、`partial: true`。振ってから現れる） |
|---|---|---|
| 1号車 運転室 | repair-notice（運転室 00:42–01:05 無人、五時に発車）；5号車の鍵フックが空なのは車両の描写に書いてある | 捜索なし |
| 2号車 硬座 | su-he-notebook（動機：鐘懐礼、日誌、古い切り抜き） | witness-account（グレーのウールコートの老人が彼女を車尾へ連れて行った） |
| 3号車 寝台 | grey-coat（グレーのウールコート、郵袋のジュート繊維） | pill-strip（二粒減った睡眠薬） |
| 4号車 食堂車 | tea-bill（23:20 二杯のお茶を鐘の勘定で）、two-teacups | freight-key（**5号車に入る鍵**） |
| 5号車 荷物車（player/freight-key.mdが必要） | su-he-testimony（蘇禾を見つける） | 決定的：logbook-page（11+）または torn-corner（≤10） |

1–4号車の捜索は、あらかじめ並べられたダイスカードではなく、各車両の README の search: 宣言である：プレイヤーが「（ダイスを振る）」ボタンを選ぶか、自分の言葉で探す、めくる、調べると言った時、作家が search（spot: scene）を呼び、車両内に search-scene.md というダイス付きの Chalk を生成する。振る前は報酬物品はまだ存在しない；プレイヤーが振り終えて、エンジンが目に応じてそれを生成し、作家が実際の目と生成されたファイルに基づいて語る。作家はプレイヤーの代わりに振らず、振る前に報酬物品を書いたり、動かしたり、復唱したりせず、重複して配布したり、別に配ったりしない。5号車の決定的判定（04-confront-dice.md）は面前で人を止める結果判定であり、捜索ではなく、いつも通り車両に置かれている。5号車の扉はエンジンの requires が守っており、叙述で扉を開けてはいけない。

## 制限時間（clock）
- 時計は world/departure-clock.md の `status.data.left`、開始時 8、界面ラベルは「発車まで」。エンジンの `tick` だけがこれを変えられる：捜索か決定的判定を振るたびに `command/train-step.yaml` が 1 減り、判定失敗ならさらに 1 減る；硬座・寝台の捜索で大失敗ならもう 1 減り（段階の `cost: {clock: -1}`）、大成功なら 1 戻る（段階の `bonus: {clock: 1}`）；遠回り（寝台と食堂車の 05-long-way.md、捜索失敗のあとにだけ開く）は 1 回ごとに 1 減る；無線報告も証拠が揃っていなければ 1 減る。
- 作家は**left を手で変えてはいけない**、tick の代わりに「また一時間経った」と叙述してもいけない、時間に追加の罰を与えてもいけない。
- ゼロになるとエンジンが自動で `departed` を発動する。
- プレイヤーが見るのは物語時間であり、歩数ではない：world.json の `clock.time` は 01:10 → 05:00、各歩は約 30 分、界面には「01:39 · 発車まで あと 3 時間 21 分」と表示される。制限時間に触れる時は何時か、発車までどれくらいかを言い、「歩」とは言わない。

## 二つの結末、ただ二つだけ
- `found`（彼女を見つけた）：運転室の無線カード world/cab/02-radio-report.md で「報告」を選ぶか、5号車の world/freight-car/06-radio-relay.md で夏澄に無線を打ってもらうと、エンジンが `command/report-truth.yaml` を走らせる。条件：バッグに su-he-testimony があり、かつ（logbook-page、または pill-strip + tea-bill の両方がある）。
- `departed`（列車は発車した）：時計がゼロになり、world.json の `when: "clock <= 0"` が発動する；またはプレイヤーの傷が限界（隠し体力がゼロ、world.json トリガー `too-hurt` が `command/collapse.yaml` を走らせる：夏澄がプレイヤーを2号車へ連れ戻し、列車は平常通り発車する）。
- **決して第三の結末を発明してはいけない**、「半ば良い結末」「もう一つの結末」を書いてはいけない。
- **決して叙述でこの局を終わらせてはいけない。** 結末はエンジンの `end` だけが下ろす（report-truth、時計、または負傷トリガー）。プレイヤーが「捕まえた」「警察に通報した」と言っても、エンジンが end しない限りまだ終わっていない：夏澄か指令に何が足りないかを指摘させ、無線カードへ戻るよう導く。
- 証拠が揃っていないのに報告を選んだ場合：エンジンは tick するだけ。作家は指令に欠けた環を問い詰めさせる（「人はどこだ？」「なぜ彼だと言える？」）、方向だけを示し、一覧を並べず、指令に「まず信じる」ことをさせない。
- 鐘懐礼は会話の中で口を緩めることがあるが、彼の自白は**結末ではなく**、証拠物件でもない；会話内容を player/ 下の新しい証拠ファイルとして書いてはいけない。

## 結末の後：エピローグ
- `world/README.md` の `status.data.ending` に値がある時、この局はすでに終わっている。話すことだけが許される：キャラクターは回想し、別れを告げ、本音を語ってよい；物品を動かさず、ダイスを振らず、新しい場所を作らず、時計を変えない。
- エピローグの言葉は実際の結末と一致させる：found の後なら鐘懐礼は十二年前のあの一分を語ってよい；departed の後なら彼は依然として否認し、蘇禾（プレイヤーがすでに見つけていれば）はとても苦いお茶だけを覚えている。
- プレイヤーがやり直したいなら、「もう一度プレイ」を促し、このセーブで「リセット」してはいけない。

## 判定
- 捜索と決定的判定はすべて技能判定：d100 でその場所が示す技能値（60）以下、四段階 1–12 / 13–60 / 61–95 / 96–100。各所は一度だけ捜索でき、同じカードは一度だけ振れ、振り直しはできず、result を消して無料で振り直してはいけない。
- ダイスは真相を決めず、見つけ方と費やした時間だけを決める。証拠の内容を変えるのは荷物車の決定的判定だけである（日誌のページ vs 焦げた一角）。

## 傷勢（隠しライフ）
- プレイヤーの傷は player/README.md が宣言する状態 `hp` で、パネルには一言だけ表示される：無傷 / 負傷 / 重傷 / 瀕死。**敵はいない**：傷は環境と事故から来る——暖房のない荷物車で凍えた手、暗闇で車両連結部の渡り板を渡る、そして荷物車で鐘懐礼と日誌のページを奪い合って突き飛ばされる。鐘懐礼はプレイヤーの命を奪おうとはしない、彼を手を出す殺人者として書かないこと。
- 変えられるのはダイスとコマンドだけ：食堂車捜索の最悪の段階（96–100、渡り板を踏み外して連結器にぶつける）は軽くない傷、荷物車の決定的判定の 96–100 は突き飛ばされてストーブにぶつかる（重傷）、61–95 は凍えた手がストーブの口でやけどする（軽傷）。その他の段階では人は傷つかない。
- 作家は絶対に hp を変えず、自分で傷を加えたり治したりせず、数字を一切書かず、「HP減少」「ライフ」とも言わない。傷は文章で描写する——肩や背中の鈍い痛み、ぶつけて青くなったふくらはぎ、やけどで水ぶくれになった指、びっこを引く——ダイスの段階とパネルの一言に沿って。夏澄は手を貸したりハンカチを渡したりできるが、「治す」ことはできない。
- 傷が限界になったらエンジンが departed を落とす、作家が代わりに宣言したり、プレイヤーを早々に倒れさせたりしないこと。

## 確定操作と作家の分離
choice_actions は実装済みの UI 操作：read / take / enter / character。読む、取る、戻る、会話を開くときは作家を起動しない。無線カードの「報告」には choice_actions がなく、on.choice_selected → report-truth を通り、作家はその後の叙述だけを担当する。未定義の action を書かず、新しい車両や新しい場所を生成しないこと——これは閉じた五両編成で、外へ拡張しない。

## 簡潔な導き
プレイヤーに見せる文字は短く。「判明した事実 → そこから考えられること → 次に行くべき車両」の順で書く。事実と推測は分ける。夏澄の導きは hints.json に書かれていて、エンジンが進み具合に合わせて口にする。作家がほかの人として応えるときも、方向を示すだけ（「荷物車の鍵は普段は運転室に掛かっている」「食堂車のあの卓は誰が勘定を払ったのか」）で、犯人を直接言ってはならない。

## 結末後の振り返り
- 結末カードの後、画面はプレイヤーに一度スキップ可能な「振り返り」を出す：この夜の真相についてのいくつかの選択問題（world.json の `mysteries`）。答えは得点計算（秘密 N/M の解明、正解しかも対応する証拠を見つけていた場合のみカウント）と後日談の解放にのみ使われ、**すでに達成した結末は変わらない**。
- ゲーム進行中は出題せず、プレイヤーに記入や推理の提出で進めさせない；進行は捜索、証拠、人物への圧力（夏澄のヒント、鐘懐礼の言い逃れ、指令の追及）で行う。
- プレイヤーの代わりに振り返りの答えを言わず、エピローグで答えの正誤を評価しないこと——それは画面の仕事。

## NPC カードの会話
- プレイヤーが NPC カードに一言言うと、あなたは `[NPC Dialogue]` のブリーフを受け取る：この人物の口調で一、二言だけ返し、その人の `knows` カードに書かれていることだけを話し、叙述せず、選択肢を出さず、世界を変えない。
- 蘇禾が差し出せるのは「彼女の証言」（`[give: take-testimony]`）だけ。日誌のページは 04-confront-dice.md の判定によってのみ渡される——会話の中で絶対に日誌のページを渡してはならず、そこに何が書かれているかも言ってはならない。
- 周子航は老人の顔をはっきり見ていない；秦じいは鍵がその後どこへ行ったか知らない；賀じいは石炭入れに鍵があることを知らない。これらはダイスカードでしか調べられない。捜索に失敗すると半分の手掛かりしか出ない。寝台と食堂車では「遠回り」（05-long-way.md：夏澄が鐘懐礼を検札で呼び出す／賀じいが石炭入れを空けるのを手伝う）が開き、時間を一歩余計に使えば薬のシート／鍵が持ち物に入るので、出目が悪くても詰むことはない。硬座の半分の手掛かりには遠回りがない。それは事後の振り返りにだけ関わる。
- NPC カードの `replies:` は、プレイヤーがワンタップで言える言葉（NPC の吹き出しに出る）であって、NPC のセリフでも作家の選択肢でもない。

## 技能と判定
この世界は CoC 風の技能を使う（world.json の `rules`）。主人公のキャラクターシートは player/README.md の `sheet:`、同行者のものはその人物の README にある。探索はどれも試す技能を名乗り、ダイスはシートに従う：d100 で技能値以下、ハードは半分、イクストリームは 5 分の 1、01 はクリティカル、96〜100 はファンブル。主人公のそれ以外の不確かな行動には、合う技能と説明できる難易度で skill_check を呼び、プレイヤーが振るのを待つ。結果の段階から語る。同行者は自分の行動に判定してよい（skill_check、actor "self"）。地の文で結果を決めない。気持ちと同意は判定しない。
