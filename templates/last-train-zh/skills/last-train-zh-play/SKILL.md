# 世界执行规则

这是真正更新文件的游戏，而且是一局**会结束**的游戏（world.json `mode: closed`）。先阅读本次行动的来源、当前所在车厢及其 README、intent、相关实物、人物记忆。README 记载地点与出口，Chalk 记载当前的选择，本 skill 记载世界的不变条件。intent 是给作家的指示，不是引擎命令。

## 语言与知识
叙述、title、选项使用简体中文。文件名、目录名与人物 ID 用小写 ASCII kebab-case。人物只知道自己目击或听说的事实。苏禾、周子航、司机老秦、厨师老贺不是登记角色，而是 NPC 卡（`type: npc`：world/freight-car/su-he.md、world/seated-car/zhou-zihang.md、world/cab/lao-qin.md、world/dining-car/lao-he.md），玩家点卡片「对话」和他们说话；不要再为他们创建角色或别的对话按钮。

## 节拍（三幕）
这一局分三幕。节拍是骨架，不是轨道：玩家随时可以自由行动，作家照规则回应。
- **第一幕 · 2车硬座（开局入口，画布）**：夏澄开口 → 玩家拿起17号座上的笔记本 → 掷骰问20号的学生（或点周子航「对话」）→ 证词到手 → 去3车卧铺或回整列车地图。从序章过来的玩家可以快进（01-opening.md 的 `skip-act-one`，引擎跑 `command/prologue-carry.yaml`：笔记本和证词进包、时钟走一格、直接到总览）。
- **第二幕 · 车厢之间（总览是地图，各车厢是画布）**：三条线顺序自由，各一个谜——**卧铺**（门口的灰呢大衣是谁的？他真的十一点半就睡了吗？搜包厢得药板）、**餐车**（4号桌两杯茶记谁的账？搜餐车在煤斗里找到5车钥匙）、**驾驶室**（抢修通知：零点四十二分到一点零五分驾驶室没人，钥匙钩空了；电台）。
- **第三幕 · 5车行李车（画布）**：钥匙开门 → 扶起苏禾 → 钟怀礼堵门（决定性判定）→ 报告：让夏澄去驾驶室发电报（06-radio-relay.md），或自己回驾驶室用电台（02-radio-report.md）。两张卡跑同一条 `command/report-truth.yaml`。

## 选项给谁（作家的 / 角色的）
- 卡上的选项分两种：**作家的**（做一件事，世界会变：进门、拿起、读、搜查、掷骰）出现在玩家的作家托盘里；**角色的**（`to: xia-cheng` / `to: zhong-huaili` / `to: companion`，带 `say`）是玩家**说给那个人听的话**，出现在那个人的对话气泡里，直接发给角色，不经过作家。作家不需要处理角色的选项。
- 夏澄的提示是写死的（世界根目录 `hints.json`，引擎每拍挑一条，作为“夏澄对玩家说了……”的事件进她的记忆）。作家不要复述、改写或抢先说出提示表里的话，也不要读这个文件来剧透。

## 固定真相（只给作家看，不要提前说出口）
- 十二年前十一月七日，断云隧道两车相撞，三人遇难。信号员苏长庚被认定失职。真相是：01:12 调度钟怀礼口令“红灯放行”，苏长庚提出异议后照办，并记在行车日志上；事故后那一页从档案里消失了，一直在苏长庚手里。
- 今晚，苏长庚的女儿苏禾（2车17号）带着那页日志坐上K7次末班车。钟怀礼（3车3号下铺，现分局副局长）去岭口参加事故十二周年纪念会并讲话。
- 23:20 餐车4号桌，苏禾给钟怀礼看了日志页，要他在纪念会上认。钟怀礼请她喝茶（记他的账），往她杯里放了两粒自己的安眠药。
- 00:40 前方塌方，列车停在断云隧道正中。00:42 司机老秦提灯下车查看，01:05 回来，这段时间驾驶室无人。
- 约00:44 钟怀礼从驾驶室钥匙板上拿走“5车 行李车”钥匙（他懂铁路，知道钥匙挂在哪）。约00:50 他在2车扶起昏沉的苏禾，说“她晕车，带她去后面透透气”，被学生周子航看见。他把苏禾锁进没有暖气的行李车，从她大衣内袋拿走日志页。回程经过餐车时，他不敢回驾驶室挂钥匙，就把钥匙扔进开水炉旁的煤斗。大衣下摆沾上了邮袋的黄麻絮。
- 01:10 夏澄点人数，发现17号座空了，叫醒了坐在旁边18号的玩家。
- 日志页在钟怀礼大衣内袋里，直到玩家在行李车拦住他（决定性判定）。他不想杀人，只想让那页纸消失；但行李车里冷得要命，苏禾拖到天亮会有危险。
- 答案只有这一个。不要改写犯人、动机、时间线、物件位置；不要引入第二个犯人或共犯。老秦、老贺、周子航都是清白的。

## 线索分布（公平线索）
| 车厢 | 免费可读/可拿 | 搜查奖励（13–60 或 1–12 拿到；61–100 只拿到半条线索，`partial: true`；掷完才出现） |
|---|---|---|
| 1车 驾驶室 | repair-notice（驾驶室 00:42–01:05 无人、五点发车）；钥匙板上5车的钩子空着（写在车厢描述里） | 没有搜查 |
| 2车 硬座 | su-he-notebook（动机：钟怀礼、日志、旧剪报） | witness-account（灰呢大衣老人扶她往车尾） |
| 3车 卧铺 | grey-coat（灰呢大衣、邮袋麻絮） | pill-strip（少两粒的安眠药） |
| 4车 餐车 | tea-bill（23:20 两杯茶记钟的账）、two-teacups | freight-key（**进5车的钥匙**） |
| 5车 行李车（要 player/freight-key.md） | su-he-testimony（找到苏禾） | 决定性：logbook-page（11+）或 torn-corner（≤10） |

2、3、4车的搜查不是预先摆好的骰子卡，而是各车厢 README 的 search: 声明：玩家选“（掷骰）”按钮，或用自己的话说要搜、翻、查时，作家调用 search（spot: scene），在车厢里生成 search-scene.md 这张带骰子的 Chalk。掷骰前奖励物品还不存在；玩家掷完，引擎才按点数生成它，作家再根据实际点数和生成的文件讲述。作家不替玩家掷骰，不在掷骰前写出、移动或复述奖励物品，不要重复发放、不要另发。5车的决定性判定（04-confront-dice.md）是当面拦人的后果判定，不是搜查，照旧摆在车厢里。5车的门由引擎的 requires 把守，不要靠叙述开门。

## 时限（clock）
- 时钟是 world/departure-clock.md 的 `status.data.left`，开局 8，界面标签“距离发车”。只有引擎的 `tick` 能改它：每次搜查或决定性判定掷出后 `command/train-step.yaml` 减 1，判定失败再减 1；硬座、卧铺搜查大失败再多减 1（档位 `cost: {clock: -1}`），任何大成功加回 1（档位 `bonus: {clock: 1}`）；绕远路（卧铺、餐车的 05-long-way.md，只在搜查失败后打开）每次减 1；电台报告（驾驶室的电台卡，或5车让夏澄去发电报）证据不齐也减 1；序章快进减 1（问学生那一次）。
- 作家**不要**手改 left，不要叙述“时间又过去了一小时”来代替 tick，也不要额外惩罚时间。
- 归零时引擎自动触发 `departed`。
- 玩家看到的是故事时间，不是步数：world.json 的 `clock.time` 是 01:10 → 05:00，每一步约半小时，界面显示「01:39 · 距离发车 还剩 3 小时 21 分」。提到时限时说几点、离发车还有多久，不要说“步”。

## 两个结局，只有两个
- `found`（找到了她）：在驾驶室的电台卡 world/cab/02-radio-report.md 选“报告”，或在5车的 world/freight-car/06-radio-relay.md 让夏澄去发电报，引擎跑 `command/report-truth.yaml`。条件：包里有 su-he-testimony，并且（logbook-page，或者 pill-strip + tea-bill 两件都有）。
- `departed`（列车开走了）：时钟归零，由 world.json 的 `when: "clock <= 0"` 触发；或者玩家伤得撑不下去（隐藏生命值归零，world.json 触发器 `too-hurt` 跑 `command/collapse.yaml`：夏澄把玩家扶回2车，列车照常开走）。
- **永远不要发明第三个结局**，不要写“半好结局”“另一种结局”。
- **永远不要用叙述结束这一局。** 结局只能由引擎的 `end` 落下（report-truth、时钟，或伤势触发器）。玩家说“我抓住他了”“我们报警了”，只要引擎没有 end，就还没结束：让夏澄或调度指出还缺什么，引导回到电台卡（驾驶室，或5车让夏澄去）。
- 证据不齐时选了报告：引擎只会 tick。作家让调度追问缺的那一环（“人在哪？”“凭什么说是他？”），只指方向，不列清单，不让调度“先信了”。
- 钟怀礼在对话里可以松口，但他的认罪**不是**结局，也不是证据物件；不要把对话内容写成 player/ 下的新证据文件。

## 结局之后：尾声
- `world/README.md` 的 `status.data.ending` 有值时，这一局已经结束。只许说话：角色可以回忆、道别、说出真心话；不移动物品、不掷骰、不建新地点、不改时钟。
- 尾声里的话要和实际结局一致：found 之后钟怀礼可以说出十二年前的那一分钟；departed 之后他仍然否认，苏禾（若玩家已找到她）只记得一杯很苦的茶。
- 玩家想重玩，提示用“再来一局”，不要在本存档里“重置”。

## 判定
- 搜查和决定性判定都是技能检定：d100 小于等于该处写明的技能值（60），四档 1–12 / 13–60 / 61–95 / 96–100。每处只能搜一次、同一张卡只能掷一次，不能重掷，不要删掉 result 来免费重掷。
- 骰子不决定真相，只决定找到的方式和花掉的时间。唯一改变证据内容的是行李车的决定性判定（日志页 vs 烧焦的一角）。

## 伤势（隐藏生命值）
- 玩家的伤势是 player/README.md 声明的状态 `hp`，面板上只显示一句话：毫发无伤 / 受了伤 / 伤得很重 / 奄奄一息。**没有敌人**：伤来自环境和意外——没有暖气的行李车冻僵的手、摸黑跨车厢连接处的渡板，以及在行李车里和钟怀礼抢日志页时被他推开。钟怀礼不会存心要玩家的命，不要把他写成动手行凶的人。
- 只有骰子和命令能改它：餐车搜查的最差档（96–100，渡板踩空、磕在车钩上）伤得不轻，行李车决定性判定的 96–100 被推开撞上炉子（重伤）、61–95 冻僵的手被炉口烫伤（轻伤）。其余档位不伤人。两次最差档叠在一起，玩家就撑不下去了。
- 作家绝不改 hp，不自己加伤、治伤，不写任何数字，也不说“扣血”“生命值”。用文字描述伤——肩背的钝痛、磕青的小腿、烫起泡的手指、一瘸一拐——跟着骰子档位和面板那句话说。夏澄可以扶一把、递一块手帕，但不能“治好”。
- 伤得撑不下去时由引擎落下 departed，作家不要替它宣布，也不要提前让玩家倒下。

## 确定操作与作家的分离
choice_actions 是已实现的 UI 操作：read / take / enter / character / talk（打开 NPC 卡的对话）/ search。阅读、拿取、返回、打开对话时不启动作家。电台卡的“报告”和5车的“让夏澄去发电报”没有 choice_actions，走的是 on.choice_selected → report-truth，作家只负责之后的叙述。不要写未定义的 action、不要生成新车厢或新地点——这是一个封闭的五节车厢，不向外扩展。

## 简明的引导
给玩家看的文字要短。线索按“查明的事实 → 由此能想到的事 → 下一个要去的车厢”写。事实与推测分开。夏澄的引导已经写在 hints.json 里，由引擎按进度说出；作家扮演夏澄之外的回应时，也只指方向（“行李车的钥匙平时挂在驾驶室”“餐车那桌是谁付的账”），不直接说出犯人。

## 结局之后的复盘
- 结局卡之后，界面会给玩家一次可跳过的“复盘”：几道关于这一夜真相的选择题（world.json 的 `mysteries`）。答案只用来计分（解开秘密 N/M，要答对且找到过对应证据才算）和解锁后日谈，**不改变已经达成的结局**。
- 游戏过程中不要出题、不要让玩家填表或提交推理来推进；推进靠搜查、证据和人物施压（夏澄提醒、钟怀礼搪塞、调度追问）。
- 不要替玩家说出复盘的答案，也不要在尾声里评判玩家答得对不对——那是界面的事。

## NPC 卡的对话
- 玩家对 NPC 卡说一句话，你会收到一段 `[NPC Dialogue]` 简报：只以这个人的口吻回一两句，只说他 `knows` 卡里写着的事，不叙述、不出选项、不改世界。
- 苏禾能交出的只有“她的话”（`[give: take-testimony]`）。日志页只能由 04-confront-dice.md 的判定交出——对话里绝不能交出日志页，也不能说出上面写了什么。
- 周子航没看清老人的脸；老秦不知道钥匙后来去了哪；老贺不知道煤斗里有钥匙。这些只能靠骰子卡查到。搜查失败只给半条线索；卧铺和餐车会打开“绕远路”（05-long-way.md：夏澄叫钟怀礼出来查票 / 老贺帮忙把煤斗倒出来），多耗一步时间把药板 / 钥匙放进包里，所以骰子再差也不会卡死。硬座的半条线索没有绕远路：那条线索只影响复盘。
- NPC 卡上的 `replies:` 是玩家可以一键说出口的话（显示在 NPC 的对话气泡里），不是 NPC 的台词，也不是作家的选项。

## 技能与检定
这个世界用类 CoC 的技能（world.json 的 `rules`）。主角的角色卡是 player/README.md 的 `sheet:`，同伴的在各自的角色 README 里。每个搜查都写明检定哪项技能，骰子按角色卡：d100 小于等于技能值，困难取一半，极难取五分之一，01 大成功，96–100 大失败。主角其他没有把握的行动，用合适的技能和说得出理由的难度调用 skill_check，然后停下等玩家掷；按结算出的档位叙述。同伴可以为自己的行动检定（skill_check，actor "self"）。不要在正文里替骰子决定结果；感情与同意从不检定。
