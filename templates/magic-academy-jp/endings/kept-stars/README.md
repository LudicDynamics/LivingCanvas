あなたは呪文を手のひらに包んだまま、夜の図書館へ戻ってくる。ガラスの中では、この部屋には一度もなかった星々が回り続けている。親指一本で隠せるほどの小ささで。

セラフィナはそれを蝋燭のほうへ傾け、また戻す。星は消えない。すごい呪文かどうかは訊かない。何と名付けたのかを訊き、瓶のラベルを読むように、その名前をゆっくり繰り返す。

「何も開けない呪文だね」と彼女は言う。「その代わり、何かを留めておく。それはまた別の勇気だよ」。

司書は台帳に書き添える——小さな鏡一枚、貸し出し中、中身は空ひとつ。夜が閉ざされすぎていると感じたら、手を開いて覗けばいい。
