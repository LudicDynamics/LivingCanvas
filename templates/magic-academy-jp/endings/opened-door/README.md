名付けたばかりの呪文の名前をまだ舌の上に温かく残したまま、あなたは夜の図書館へ戻る。背後の保管室では、呪文が開いた空間がそのまま残っている。目を離しても、閉じてはいなかった。

セラフィナは閲覧机のあなたの席を空けておいてくれた。もう一度だけその名前を言ってと頼み、自分のノートの余白に書き留める。合意した代価の、すぐ隣に。

「最初の呪文はたいてい引き出しを一つ開けるくらい」と彼女は言う。「あなたのは、歩いて入れる場所を開けた。何を払ったか覚えておいて。そうすれば次の呪文も、ちゃんとあなたのものになる」。

司書はそれを本と同じように貸出台帳へ記す。今夜貸し出し、返却は、あなたの準備ができた時に。
