あなたは材料を元の場所へ戻す。まだ温かい星の欠片、蝋燭の光だけを映す手鏡、一度も声に出さなかった二つの言葉。

セラフィナは引き止めない。あなたの草稿を一度だけ折って、ノートの後ろに挟む。「唱えなかった呪文は、まだ何も奪っていない」と彼女は言う。「ただ、まだ起きていないだけ」。

司書は今夜、何も貸出に記さない。帰りがけに名札を見下ろすと、名前の欄はまだ白紙のままだ。

明日の夜も、図書館は同じ時刻に開く。材料は、あなたが置いた場所で待っている。
