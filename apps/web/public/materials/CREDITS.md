# Paper material

`ivory-paper-v1.webp` was generated with the built-in image generation tool
using the imagegen skill, then resized to 512 × 512 and encoded as WebP
(quality 72). The runtime file is approximately 2.3 KB.

Final prompt:

Use case: photorealistic-natural. Asset type: subtle paper surface texture for an immersive narrative game's in-place readable document, not a UI mockup. Primary request: a flat, seamless, tileable square photograph of clean uncoated ivory writing paper, extremely subtle natural cellulose fibers and barely visible grain, softly varied neutral warm off-white #e2ddd1. Orthographic close-up, even diffuse lighting, understated realistic stationery, nearly uniform light center, low contrast suitable behind small dark readable Japanese and English text. Edge-to-edge material only. No sheet outline, no borders, no folds, no tears, no stains, no burnt edges, no heavy yellow/brown aging, no desk, no objects, no text, no letters, no icons, no watermark. Small reusable UI texture rather than a large decorative illustration.
